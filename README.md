# AXEdex — симулятор казино

**AXEdex** — розважальний симулятор казино на **віртуальні фішки**: 19 ігор, рівні, досягнення та жорстка економіка, у якій кожну фішку доводиться берегти. Реальних грошей, депозитів, виведень, криптовалют і платіжних систем тут немає, фішки не можна купити.

Зроблено by **kyrapyto**.

Інтерфейс повністю українською, у стилі Dark Luxury (графіт, неоновий смарагд, глибоке золото, скло з розмиттям), адаптований для комп’ютерів і смартфонів. Прогрес зберігається в браузері гравця (`localStorage`).

## Ігри

| Категорія | Ігри |
| --- | --- |
| Настільні | Кібер-рулетка (європейська), Дуель кісток (Більше/Менше та Крепс-лайт), Сік-бо |
| Карткові | Елітний блекджек, Відеопокер «Валети або старше», Вище-Нижче, Бакара, Дракон і Тигр |
| Слоти та колеса | Неон-слоти 777 (5×3, 10 ліній, вайлди, фриспіни), Колесо фортуни |
| Швидкі | Ракета (Crash), Авіатор: Посадка на крейсер, Плінко, Міни, Кено, Лімбо, Вежа, Монетка, Скретч-картка |

Кожна гра має правила, теоретичну віддачу (RTP) і статистику. Усі результати генеруються через `crypto.getRandomValues`, а таблиці виплат перевірено тестами (точний розрахунок або симуляція).

## Економіка

| Джерело фішок | Скільки |
| --- | --- |
| Стартовий баланс | 1 000 |
| Щоденний бонус | 100, +50 за кожен день серії, максимум 400 |
| Допомога банку | 250, лише коли на балансі менше 10, і не частіше ніж раз на 8 годин |
| Новий рівень | 20 × номер рівня |
| Досягнення | 50 / 150 / 500 / 1 500 (бронза / срібло / золото / платина) |

Номінали фішок: 1, 5, 10, 25, 100, 500. Усі ігри мають перевагу казино, тож на довгій дистанції баланс тане.

### Авіатор: Посадка на крейсер

Повністю автоматичний політ: гравець обирає лише ставку й темп анімації. Літак злітає з лічильником ×1 і знижується над морем. Бонуси +0,2×…+5× та множники ×2, ×3, ×5 додаються до лічильника й підкидають літак угору (що більший «ікс», то вище), ракети ділять лічильник навпіл і збивають висоту. Коли висота закінчується, літак сідає на крейсер (ставка × лічильник, шанс 47%) або падає в море. Весь політ визначається в момент зльоту (`src/games/carrier/logic.ts`), віддача 96,7% перевірена симуляцією в тестах.

## Можливості платформи

- **Гаманець і журнал раундів.** Кожна гра списує ставку й зараховує виплату через спільний журнал, тому раунд, перерваний переходом на іншу сторінку чи перезавантаженням, завжди розраховується чесно.
- **Прогрес:** рівні й досвід, 33 досягнення, статистика кожної гри, графік балансу.
- **Лобі:** пошук, категорії, обране, «гра дня», стрічка подій, таблиця останніх ставок, найближчі цілі.
- **Збереження:** автоматично в браузері, синхронізація між вкладками, резервна копія у файл і її відновлення (Профіль → Налаштування).
- **Продуктивність:** статичний фон, тож скляні панелі не перемальовуються щокадру; канвас-ігри зупиняються поза екраном; режим якості «Авто / Висока / Економ» з автоматичним визначенням слабких пристроїв.
- **Звук** синтезується через Web Audio API, без аудіофайлів. Анімації зроблено на Motion і Canvas.

## Технології

React 19, TypeScript, Vite, Tailwind CSS 4, Motion (Framer Motion), Zustand, Lucide, Vitest, Oxlint. Шрифти Manrope, Exo 2 і JetBrains Mono підключено локально через Fontsource.

## Запуск

```bash
npm ci
npm run dev        # режим розробки
npm test           # тести ігрової логіки та гаманця
npm run lint       # лінтер
npm run build      # продакшн-збірка в dist/
```

## Публікація на GitHub Pages

Workflow `.github/workflows/deploy.yml` збирає, перевіряє й публікує сайт після кожного push у `main`.
Один раз увімкніть Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Сайт буде доступний за адресою `https://<власник>.github.io/AXEdex/`. Маршрутизація через hash (`#/play/roulette`), тому налаштовувати сервер не потрібно.

## Структура

```
src/
  store/        гаманець, журнал раундів, досвід, досягнення, резервні копії
  games/<id>/   логіка (logic.ts + тести) та інтерфейс кожної гри
  components/   оболонка, UI-кіт, спільні ігрові компоненти
  pages/        лобі та профіль
  audio/        синтезатор звуків
scripts/        генерація набору SVG-гліфів
```
