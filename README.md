# AXEdex — симулятор казино

**AXEdex** — развлекательный симулятор казино на **виртуальные фишки**: 18 игр, уровни, достижения и жёсткая экономика, в которой каждую фишку приходится беречь. Реальных денег, депозитов, выводов, криптовалют и платёжных систем здесь нет, фишки нельзя купить.

Интерфейс полностью на русском языке, адаптирован для компьютеров и смартфонов. Прогресс хранится в браузере игрока (`localStorage`).

## Игры

| Категория | Игры |
| --- | --- |
| Настольные | Кибер-рулетка (европейская), Дуэль костей (Больше/Меньше и Крэпс-лайт), Сик-бо |
| Карточные | Элитный блэкджек, Видеопокер «Валеты или старше», Выше-Ниже, Баккара, Дракон и Тигр |
| Слоты и колёса | Неон-слоты 777 (5×3, 10 линий, вайлды, фриспины), Колесо фортуны |
| Быстрые | Ракета (Crash), Плинко, Мины, Кено, Лимбо, Башня, Монетка, Скретч-карта |

У каждой игры есть правила, теоретическая отдача (RTP) и статистика. Все исходы генерируются через `crypto.getRandomValues`, а таблицы выплат проверены тестами (точный расчёт или симуляция).

## Экономика

| Источник фишек | Сколько |
| --- | --- |
| Стартовый баланс | 1 000 |
| Ежедневный бонус | 100, +50 за каждый день серии, максимум 400 |
| Помощь при банкротстве | 250, только при балансе меньше 10 и не чаще раза в 8 часов |
| Новый уровень | 20 × номер уровня |
| Достижения | 50 / 150 / 500 / 1 500 (бронза / серебро / золото / платина) |

Номиналы фишек: 1, 5, 10, 25, 100, 500. У всех игр есть преимущество казино, поэтому на длинной дистанции баланс тает.

## Возможности платформы

- **Кошелёк и журнал раундов.** Каждая игра списывает ставку и зачисляет выплату через общий журнал, поэтому раунд, прерванный переходом на другую страницу или перезагрузкой, всегда рассчитывается честно.
- **Прогресс:** уровни и опыт, 32 достижения, статистика по каждой игре, график баланса.
- **Лобби:** поиск, категории, избранное, «игра дня», лента событий, ближайшие цели.
- **Сохранение:** автоматически в браузере, синхронизация между вкладками, резервная копия в файл и её загрузка (Профиль → Настройки).
- **Звук** синтезируется через Web Audio API, без аудиофайлов. Анимации сделаны на Motion и Canvas.

## Технологии

React 19, TypeScript, Vite, Tailwind CSS 4, Motion (Framer Motion), Zustand, Lucide, Vitest, Oxlint.

## Запуск

```bash
npm ci
npm run dev        # режим разработки
npm test           # тесты игровой логики и кошелька
npm run lint       # линтер
npm run build      # продакшен-сборка в dist/
```

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает, проверяет и публикует сайт при каждом push в `main`.
Один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Сайт будет доступен по адресу `https://<владелец>.github.io/AXEdex/`. Маршрутизация через hash (`#/play/roulette`), поэтому настраивать сервер не нужно.

## Структура

```
src/
  store/        кошелёк, журнал раундов, опыт, достижения, резервные копии
  games/<id>/   логика (logic.ts + тесты) и интерфейс каждой игры
  components/   оболочка, UI-кит, общие игровые компоненты
  pages/        лобби и профиль
  audio/        синтезатор звуков
public/icons/   цветные иконки (SVG)
```
